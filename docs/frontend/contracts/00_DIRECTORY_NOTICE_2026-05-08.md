# Frontend Contracts Directory

This folder contains frontend-specific contract documents.

Each contract describes the expected shape, taxonomy, and behavioral boundary between domain logic and UI presentation. Contracts here are source-of-truth for the mapping layer, not for runtime implementation details.

Treat files in this folder as living contracts. When runtime code diverges from a contract, update the contract or file an issue — do not let silent drift accumulate.
