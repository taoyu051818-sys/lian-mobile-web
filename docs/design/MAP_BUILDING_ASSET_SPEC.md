# LIAN 地图 2.5D 建筑图像设计规范

LIAN 校园地图建筑资产设计与命名规范。

本文档定义地图建筑图像的命名约定、尺寸规范、风格指南和文件格式要求，确保地图资产的一致性和可维护性。

## 1. 命名约定

### 1.1 基本规则

所有建筑资产文件名必须使用**英文 kebab-case**（小写字母 + 连字符）：

```text
正确：library.png, lian-academy.png, life-zone-1.png
错误：黎安书院.png, LifeZone1.png, life_zone_1.png
```

### 1.2 命名结构

```text
{建筑英文名}[-{变体}].{扩展名}
```

| 组成部分     | 说明                            | 示例                                     |
| ------------ | ------------------------------- | ---------------------------------------- |
| 建筑英文名   | 建筑的英文标识，使用 kebab-case | `library`, `lian-academy`, `life-zone-1` |
| 变体（可选） | 透明版本、不同状态等            | `-transparent`, `-night`, `-highlight`   |
| 扩展名       | 文件格式                        | `.png`, `.webp`                          |

### 1.3 透明版本约定

带透明背景的版本使用 `-transparent` 后缀：

```text
library.png              # 标准版本（可能带背景）
library-transparent.png  # 透明背景版本
```

### 1.4 命名词表

| 中文名称        | 英文命名                | 说明              |
| --------------- | ----------------------- | ----------------- |
| 图书馆          | `library`               |                   |
| 黎安书院        | `lian-academy`          | LIAN 学院主楼     |
| 体育馆 / 运动场 | `bupt-sport`            | 北邮体育设施      |
| 生活区 1 号楼   | `life-zone-1`           | 宿舍 / 生活区建筑 |
| 生活区 2 号楼   | `life-zone-2`           |                   |
| 食堂            | `canteen-{n}`           | n 为食堂编号      |
| 教学楼          | `teaching-building-{n}` |                   |
| 行政楼          | `admin-building`        |                   |

## 2. 尺寸规范

### 2.1 基准尺寸

建筑资产的**基准尺寸**为 **128x128 像素**（1x 倍率）。

实际尺寸根据建筑在地图上的视觉重要性和物理大小调整：

| 建筑类型 | 推荐尺寸 (1x)     | 说明           |
| -------- | ----------------- | -------------- |
| 地标建筑 | 192x192 ~ 256x256 | 图书馆、主楼等 |
| 标准建筑 | 128x128 ~ 160x160 | 教学楼、宿舍楼 |
| 小型设施 | 64x64 ~ 96x96     | 亭子、小卖部   |

### 2.2 缩放比例

为适配不同设备像素密度，提供以下缩放版本：

| 倍率 | 后缀           | 基准 128px 对应尺寸 | 用途              |
| ---- | -------------- | ------------------- | ----------------- |
| 0.5x | `-0.5x`        | 64x64               | 低分辨率 / 缩略图 |
| 1x   | 无后缀         | 128x128             | 标准分辨率        |
| 2x   | `-2x` 或 `@2x` | 256x256             | 高分辨率 / Retina |

示例：

```text
library.png        # 1x 版本
library-2x.png     # 2x 版本
library@2x.png     # 2x 版本（Apple 风格命名，也可接受）
```

### 2.3 地图渲染尺寸

在 `useMapLayers.ts` 中，资产通过 `MapAsset.size` 属性控制渲染尺寸：

```typescript
interface MapAsset {
  size?: [number, number]; // [宽度, 高度]，默认 [64, 64]
  anchor?: [number, number]; // 锚点，默认 [width/2, height]
  // ...
}
```

建议渲染尺寸与图像实际尺寸匹配，避免模糊或锯齿。

## 3. 风格指南

### 3.1 视角

采用 **2.5D 等轴视角**（Isometric）：

- 俯视角度约 30-45 度
- 建筑呈现三个可见面（顶面、左侧面、右侧面）
- 所有建筑保持相同的视角方向

```text
      ___________
     /          /\
    /          /  \
   /          /    \
  /__________/      \
  \          \      /
   \          \    /
    \          \  /
     \__________\/
```

### 3.2 阴影方向

所有建筑阴影统一为**右下 45 度**：

- 光源位于左上方
- 阴影投射到建筑右下方
- 阴影颜色使用半透明深色（如 `rgba(0, 0, 0, 0.15)`）
- 阴影长度约为建筑高度的 30-50%

### 3.3 色调

遵循 LIAN 滨海校园视觉风格：

| 色彩类型 | 色值范围         | 说明           |
| -------- | ---------------- | -------------- |
| 主色调   | 米白、浅灰、暖白 | 建筑主体       |
| 强调色   | `#1fa7a0` 蓝绿   | 屋顶、装饰     |
| 辅助色   | `#5bb8d6` 海岸蓝 | 玻璃、水面反光 |
| 植被色   | `#78b66b` 草地绿 | 周边绿化       |

避免：

- 过于鲜艳的纯色
- 政务蓝、企业灰
- 与 LIAN 品牌色冲突的色调

### 3.4 细节层次

| 缩放级别           | 细节要求             |
| ------------------ | -------------------- |
| 远景（zoom < 16）  | 轮廓清晰，省略小细节 |
| 中景（zoom 16-18） | 显示门窗、主要结构   |
| 近景（zoom > 18）  | 可显示更多装饰细节   |

当前地图主要使用中景级别，建议：

- 保留建筑主要特征（如图书馆的玻璃幕墙、书院的传统屋顶）
- 简化重复元素（窗户可用规律图案表示）
- 确保 64px 缩放后仍可辨识

## 4. 文件格式

### 4.1 推荐格式

| 格式     | 用途 | 说明                         |
| -------- | ---- | ---------------------------- |
| **PNG**  | 首选 | 支持透明通道，无损压缩       |
| **WebP** | 可选 | 更小体积，需检查浏览器兼容性 |

### 4.2 PNG 规范

- 色彩模式：RGBA（32 位，带 Alpha 通道）
- 压缩：使用 PNG-8 或 PNG-24，优先体积优化
- 透明度：建筑主体不透明，背景完全透明（Alpha = 0）

### 4.3 文件大小建议

| 尺寸    | 建议文件大小 |
| ------- | ------------ |
| 64x64   | < 10 KB      |
| 128x128 | < 30 KB      |
| 256x256 | < 80 KB      |

使用工具优化：`pngquant`、`optipng`、`tinypng`

### 5.2 迁移步骤

1. **重命名中文文件**：

   ```bash
   # 如果 黎安书院.png 与 lian-academy.png 内容不同
   mv "黎安书院.png" "lian-academy-alt.png"
   mv "黎安书院-transparent.png" "lian-academy-alt-transparent.png"

   # 如果内容相同，直接删除中文版本
   rm "黎安书院.png" "黎安书院-transparent.png"
   ```

2. **更新引用**：搜索代码中对 `黎安书院` 的引用，替换为新文件名

3. **验证渲染**：在地图上确认建筑正常显示

## 6. 新增资产流程

### 6.1 设计检查清单

- [ ] 文件名使用英文 kebab-case
- [ ] 提供标准版本和 `-transparent` 版本
- [ ] 尺寸符合基准规范（128x128 或合理变体）
- [ ] 视角为 2.5D 等轴视角
- [ ] 阴影方向为右下 45 度
- [ ] 色调符合 LIAN 滨海校园风格
- [ ] 文件格式为 PNG（带透明通道）
- [ ] 文件大小已优化

### 6.2 提交要求

新增建筑资产的 PR 应包含：

1. 资产文件（标准版 + 透明版）
2. 更新本文档的资产清单
3. 如需在地图上显示，同步更新 `data/map-layers.json` 或相关配置
